## Intended execution path

The authenticated backend supplies the current company's trusted worker inventory
and original goal to the VPS. The VPS selects an eligible worker by capability,
platform, heartbeat, permitted hours and load. An explicit target stays binding.
The existing Connector queue retains the job, Stop and correlated result; retries
reuse the same request/job ID and first worker. A selection, heartbeat or queued
acknowledgement does not mean the work completed.

| Work requested | Executor | Required result |
| --- | --- | --- |
| Existing server tools / company sandbox work | VPS, through the existing server authorization/accounting path | Actual tool result, useful artifact where requested, independent read-back and receipt |
| Mouse, keyboard, native browser or app goal | Eligible company computer advertising `desktop_task` and owner-enabled Full Control | Observed screen effects, exact goal and terminal Connector receipt |
| Files, commands, browser plan or supported launcher | Company computer advertising that operation | Matching worker, operation and parameters; actual result/receipt |
| Explicit Mac / Safari request | Compatible Mac in the same company | That Mac's own result; no silent substitution with Debian |

Company desktop workers are not the same as private, isolated platform workers
serving unrelated customer companies. PR104's text-digest prototype does not
complete that separate architecture.

Engine, Agents, Memory, Learning/Traces and Query Flow documentation. They contain
no new VPS installer output or execution receipts. Their feature lists describe
framework availability and proposed work; they are not proof of installed runtime
integration. Learning routes **models**; FIRBO dispatch routes **execution workers**.

not execute a tool loop. Memory needs ingestion and retrieval wiring; traces need
actual event collection; proposed/stub features must stay labelled as such.

suite passed 302 tests with synthetic transports; live provider availability still
requires acceptance. No research reinstall is needed to enable those source paths.
